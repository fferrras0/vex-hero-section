# VEX Hero Section

A pixel-perfect hero section built with **React + TypeScript + Tailwind CSS + Vite**.

## Features

- Full-screen video background (raw, no overlay/dimming)
- Liquid glass navbar and UI elements
- Character-by-character animated heading with staggered delays
- FadeIn wrapper component with configurable delay and duration
- Inter font via Google Fonts
- Fully responsive (mobile → desktop)

## Stack

- React 18 + TypeScript
- Tailwind CSS v3
- Vite 5

## Getting Started

```bash
npm install
npm run dev
```

Then open [http://localhost:5173](http://localhost:5173).
